# 📊 Freelancer Analytics Dashboard — Microsoft Excel

## 📌 Project Overview

This project focuses on cleaning, transforming, analyzing, and visualizing a dataset of **1,000 freelancers** using Microsoft Excel.

The objective of this project was to transform raw and inconsistent freelancer data into a structured, analysis-ready dataset and develop an interactive dashboard to present meaningful insights.

---

## 🎯 Project Objectives

- Clean and standardize raw freelancer data
- Identify and remove duplicate Freelancer IDs
- Standardize freelancer names and gender values
- Categorize freelancers based on years of experience
- Clean and standardize hourly rate data
- Standardize Active / Not Active status
- Convert client satisfaction values into percentage format
- Create Pivot Tables for analysis
- Develop Pivot Charts for visualization
- Add interactive Slicers
- Design a professional Excel dashboard

---

## 🧹 Data Cleaning

The raw dataset contained inconsistent and unformatted values.

The following data-cleaning operations were performed:

| Data Field | Cleaning Operation |
|---|---|
| Freelancer ID | Checked and removed duplicates |
| Full Name | Removed Mr., Mrs., and Dr. titles |
| Gender | Standardized values to `male` and `female` |
| Years of Experience | Classified into experience ranges |
| Hourly Rate | Removed `$` and `USD` symbols and converted to numeric values |
| Status | Standardized values to `Active` and `Not Active` |
| Client Satisfaction | Converted values into consistent percentage format |

---

## 📊 Data Analysis

Pivot Tables were created to analyze the following metrics:

### 1. Average Rating by Primary Skill

Analyzed the average freelancer rating across different primary skills.

### 2. Freelancer Count by Years of Experience

Analyzed the number of freelancers in each experience category:

- 0–5
- 6–10
- 11–15
- 16–20
- 21+

### 3. Freelancer Distribution by Hourly Rate

Analyzed the distribution of freelancers based on hourly rate.

### 4. Freelancer Count by Language

Analyzed the number of freelancers available for each language.

### 5. Freelancer Count by Country

Analyzed the geographical distribution of freelancers.
